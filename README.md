This project is the product of a group project for an Object-Oriented Programming (OOP) course. The goal of the project was to design and develop a Simple Banking System that demonstrates fundamental object-oriented programming concepts while incorporating user validation and account security.

The system allows users to interact with a basic banking environment where they can create and manage accounts, perform common banking operations, and have their information validated before accessing certain features.

The project was developed as a practical application of concepts such as classes and objects, encapsulation, inheritance, methods, conditional logic, and user input validation.
